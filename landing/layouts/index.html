ONE CONTINUOUS WORKFLOW

Keep the story of each release current.

Start from a new file or existing Git history, then refine the words before they become release notes.

01 / START

Initialize or backfill

Create a Keep a Changelog file, or assemble missing release sections from local tags and commits.

kaclm create
02 / EDIT

Work in Unreleased

Add, list, and edit entries while changes are fresh. Task lists and fragments can feed the same flow.

kaclm add --change-type added --message "New feature"
03 / CHECK

Validate and preview

Catch structure problems and inspect the next version before promoting Unreleased.

kaclm validate
